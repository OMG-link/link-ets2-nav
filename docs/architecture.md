# 导航事件与测速预警设计

## 数据流

游戏通信 DLL → 不可变遥测与路线快照 → 地图匹配 → 已确认路径上的关键事件 → 上游语音触发点 → 合成文件缓存 → 到期触发 → 独立优先级播放队列。

导航动作和测速探头使用同一种事件、触发点模型。当前已确认的连续路线构成事件表，地图继续加载后可追加后续事件；不要求初始化时解析完整行程。导航事件使用稳定路线里程，SDK 裁掉已行驶的路线前缀时仍保留触发点坐标。测速沿路距离可用时对齐同一里程；无导航或使用直线距离时保留独立距离依据。

插件只读取游戏数据，不控制车辆，不修改地图，不阻止测速或罚款。第一阶段支持官方地图及实际挂载的 DLC；不会将已安装但当前未挂载的地图默认当成有效地图。

## 地图与挂点

附近区块通过 TruckLib 的指定区块读取接口加载，归档读取器由插件独立持有，避免和宿主共享可变文件流。归档挂载与扫描由独立后台任务串行执行，进入新的区块窗口时重新读取区块，保留当前位置窗口及模型元数据缓存。扫描完成后通过短锁发布完整快照；预警循环只取快照引用，方向与距离匹配在锁外执行。刷新未完成或刷新失败时继续使用上一份已准备地图，首次加载则等待可用快照。移动期间待处理扫描请求只保留最新位置，不积压任务。会话或地图来源变化立即使旧快照和在途结果失效；取消任务后先等待读取退出，再释放归档，避免文件流被并发使用或提前关闭。探头和道路关联在接近后计算，不预生成全地图的预警触发点。

探头身份来自真实 `speed_camera` 挂点。模型名称、外观及普通摄影机条目不是测速证据。PMG 解析仅读取挂点元数据，不解码网格；底层归档仍可能解压完整资源条目。

原始挂点位置、模型朝向、测速方向和实际监测位置是不同概念。未验证的方向、模型变体或监测位置不能参与自动播报。地图重新加载时重新计算世界坐标。

## 路径与距离

有导航时，以经过顺序和行驶方向确认监测位置位于前方路线，优先采用道路折线弧长。地图曲线以短间隔采样，距离为近似值，不宣称厘米级精度。

不能恢复连续道路几何时，只能在独立确认车辆与目标均属于同一条有序导航路线、且目标在前方后使用直线距离。不能用“距离路线很近”代替道路归属。路线几何缺口两侧仍保留已知道路弧长，并以缺口端点的直线距离作为未知部分的最小长度；这个路线长度下限只能推迟触发，不能作为完整沿路距离。它防止绕行或掉头后才会经过的近邻反向探头，提前按眼前直线距离消费预警阶段。SDK 节点距离不直接当作地图几何米数使用。

无导航时，仅接受当前道路和能够证明唯一的 Road 连接链；已解析的 PPD 导航曲线可以连接唯一出口的预制件；遇到多个合法出口、缺失引用或循环即停止拓扑推断。不以朝向锥形区域代替必经性。

平行道路、不同高度道路、重复经过同一区域的路线必须消除歧义，无法消除时不预警。预制件内部使用 PPD 的有向导航曲线及其连接关系恢复入口到出口的几何；控制节点位置无法验证或资源格式不支持时仍拒绝匹配，不能以直线跨越整个路口。

## 预警状态

- 默认在 500 米、200 米处各触发一次；首次识别在两阈值之间允许立即提示，首次已不足 200 米或一次采样跨过两阈值时仅提示近距离阶段。
- 沿路距离优先；仅在沿路距离确实不可用时使用已确认目标的直线距离。
- 同一次接近的两个阶段独立去重；经过后不再新增该次接近的阶段，但已入队语音按统一播放规则处理。进入监测位置 20 米近域并离开至少 50 米后，还需重新确认接近才允许再次触发。连续道路的正向剩余距离可确认新一轮接近；仅有直线回退时，要求相对离开后的最远距离至少缩短 5 米，避免刚离开 50 米就重复播报。物理上靠近但已知路线长度下限仍很远的目标，不计作已经接近监测位置。
- 路线重算不重复播报同一目标；传送、读档、断线重连和地图来源变化会重置相关状态。
- 暂停、倒车、无效或过期快照不触发；未知路线不等同于没有设置路线。取消导航后，只有新鲜且持续推进的遥测在至少一秒、至少三次模拟更新中明确报告剩余距离为零，才会丢弃持续重发的旧路线节点，进入无导航模式。
- 快照时间取遥测接收时刻，磁盘读取耗时不能让旧样本伪装成新样本。

## 实验限速解析

后台读取国家货车限速、道路默认车道类别、城市矩形、交通区域及标牌规则。定义叠加当前获准模组的目录或 ZIP 内容；不支持的归档或解析失败会使限速保持未知，不影响探头扫描。几何资源仍使用已有官方挂载。标牌的近邻道路归属在扫描任务中建立，避免给预警循环增加大量空间搜索。

从玩家当前位置出发，沿当前游戏导航路径模拟至探头监测位置；无导航时使用已确认的唯一必经路径。以 SDK 当前实际限速初始化临时限速，只依次应用当前位置之后、探头之前的标牌事件。新限速覆盖上一临时值；遇到解除标牌时一次清空全部临时限速，恢复使用探头位置的道路与区域默认规则，不维护叠加栈。国家货车上限、道路类别和交通区域规则继续使用既有组合逻辑。相同探头的估算随当前位置、路径和 SDK 初值重新计算，不按探头缓存结果；地图加载阶段仅缓存标牌归属及投影等静态数据。

标牌方向暂以本地 -Z 约定和道路切向匹配；FollowRoadDir 采用保留原始方向的切向近似，尚未完全复现游戏车道对齐。到探头的路径不连续、标牌归属或作用未确认、道路类别或国家规则缺失等情况返回未知。这是实验估算，未解析的标牌和特殊车道规则仍可能影响结果，不能声称与游戏引擎完全一致。SDK 当前限速及其变化位置单独记录，罚单记录也带该采样值；当前 SDK 值仅作为模拟初值，诊断页和目标日志显示沿路径模拟后的估算及依据。运行时不再持续比较玩家当前位置的推断限速与 SDK 实际限速。

## 事件、触发点与音频

普通路口的直行、左转、右转、掉头和左右前方使用同一导航动作链及同一规划流程。直行也以自己的真实结束点约束后续动作，不另设 50 米 passage 或直行安静期；已证明的主路延续不产生操作语音。所有普通预告与执行点均位于前一动作的真实结束点之后：固定距离档位由首次锚点筛选，20 米执行点也按该边界约束，恰在边界时须严格越过才触发。前驱结束点未知时保持待定，不用其入口代替。

`NavigationEventPlanner` 将当前已确认的动作序列转换为 `GuidanceEvent` 和 `SpeechTrigger`，测速规划则提供相同模型的普通距离预告：只有 500／200 米两个档位，没有独立执行档位，也没有额外播放优先级。未来动作首条简报在规划阶段就安插于前一动作的真实结束坐标，并据两位置计算固定文案，音频可立即准备；不再由每帧当前动作选择启用触发。导航与环境是独立的前驱链，环境内部仅同类事件相互约束，测速不阻挡车道通知或导航。环境首个可播距离不足 500 米时按 50 米向下取整并跳过 200 米档，低于 50 米使用不带距离文案。临时无法确认路径时暂停该来源的触发，不清除已经入队的语音。

`GuidanceTimeline` 保存事件表，`SpeechTriggerScheduler` 只负责消费到期且未消费的触发点，不直接播放或等待合成。导航距离档位为 2000／1000／500／200／100 米，另有距动作约 20 米的执行触发点。100 米档在触发当时车速达到 60 km/h 时消费但不播报；规划及预生成仍包含它。路线前缀缩短时由 `RouteProgressTracker` 对齐坐标；一帧跨过路口、动作刚从识别结果消失时，仍消费刚跨过的执行点。

`SpeechAnnouncementQueue` 只负责生产和复用音频文件；`GuidancePlaybackManager` 独占生产流程中的播放选择。执行提示优先于普通预告，其余按入队顺序选择已就绪音频，一条真正播放完成后才选择下一条。尚未合成好的语音保留在待播队列，且比远期预生成任务优先准备；合成失败或未启用 TTS 时才使用配置的提示音。队列没有按年龄丢弃规则；同一语音系列的后续阶段入队时替换该系列尚未播放的前一阶段，不中断已经开始的音频。

每个系列可提供独立的结束位置，路口取预制件出口、环岛两个系列取整个组件出口、测速取监测点。结束位置未能确认时不推测；有向监测点通过事实可补足无绝对里程的测速结束。调度器将触发点和结束点按沿路顺序消费，严格越过结束位置后撤销该系列待播项；新增和结束撤销在一个锁内批量提交后才允许播放器选择下一条，沿用原有已消费账本，不另设永久结束缓存。

路线重算撤销旧路线独有且尚在前方的事件，共有事件及其待播项继续保留。正常行驶导致路线前缀缩短或地图窗口变化，不等于重算，不因此删除待播项。暂停保留队列并停止选择下一条，恢复后继续；已经开始的音频允许播完。读档、传送、断线重连、地图来源变化和关闭插件清理队列，已开始的音频不再计入新会话。

Kokoro 在独立的常驻 .NET 子进程中串行合成，模型首次缓存未命中才加载；插件扫描线程不等待推理。缓存键绑定文本、音色、模型与词典内容指纹以及引擎设置，输出 WAV 和校验元数据以原子替换方式保存；命中时校验结构与 SHA-256。相同文案共用文件，已经开始的生成任务可完成缓存。探头限速文案仍随当前路径重新计算，排队期间可更新待播文案；音频缓存不等于缓存探头限速结果。

插件页面 `/link-ets2-nav` 展示事件数、触发点、启用状态、待播队列、最近触发及播放完成状态，同时保留附近目标和拒绝播报原因。`motion.jsonl` 包含统一规划诊断，便于离线重放。只读探测工具检查本地游戏资源，不需要启动游戏，不随插件 DLL 分发。

## 验证边界

合成地图测试验证路径、方向、距离、去重、时效和生命周期规则；本机资源探测验证文件解析。二者不能替代游戏内测速方向及实际监测位置的标定。
