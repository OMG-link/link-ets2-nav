# 测速探头预警设计

## 数据流

游戏通信 DLL → 遥测与路线事件 → 不可变快照 → 附近地图区块与探头挂点 → 道路归属和方向匹配 → 预警状态机 → 音频接口。

插件只读取游戏数据，不控制车辆，不修改地图，不阻止测速或罚款。第一阶段支持官方地图及实际挂载的 DLC；不会将已安装但当前未挂载的地图默认当成有效地图。

## 地图与挂点

附近区块通过 TruckLib 的指定区块读取接口加载，归档读取器由插件独立持有，避免和宿主共享可变文件流。进入新的区块窗口时重新读取区块，保留当前位置窗口及模型元数据缓存。探头和道路关联在接近后计算，不预生成全地图的预警触发点。

探头身份来自真实 `speed_camera` 挂点。模型名称、外观及普通摄影机条目不是测速证据。PMG 解析仅读取挂点元数据，不解码网格；底层归档仍可能解压完整资源条目。

原始挂点位置、模型朝向、测速方向和实际监测位置是不同概念。未验证的方向、模型变体或监测位置不能参与自动播报。地图重新加载时重新计算世界坐标。

## 路径与距离

有导航时，以经过顺序和行驶方向确认监测位置位于前方路线，优先采用道路折线弧长。地图曲线以短间隔采样，距离为近似值，不宣称厘米级精度。

不能恢复连续道路几何时，只能在独立确认车辆与目标均属于同一条有序导航路线、且目标在前方后使用直线距离。不能用“距离路线很近”代替道路归属。

无导航时，仅接受当前道路和能够证明唯一的 Road 连接链；遇到预制件、分岔、缺失引用或循环即停止拓扑推断。不以朝向锥形区域代替必经性。

平行道路、不同高度道路、重复经过同一区域的路线必须消除歧义，无法消除时不预警。预制件内部车道和导航节点映射需单独支持，不能以直线连接跨越。

## 预警状态

- 默认阈值 300 米；首次获得可信目标时已经在阈值内也允许提示。
- 沿路距离优先；仅在沿路距离确实不可用时使用已确认目标的直线距离。
- 同一次接近只播报一次；离开至少 600 米后才允许再次触发。
- 路线重算不重复播报同一目标；传送、读档、断线重连和地图来源变化会重置相关状态。
- 暂停、倒车、无效或过期快照不触发；未知路线不等同于没有设置路线。
- 快照时间取遥测接收时刻，磁盘读取耗时不能让旧样本伪装成新样本。

## 音频与诊断

预警事件包含目标标识、距离和距离类型，经 `IWarningAnnouncer` 输出。当前实现使用宿主固定提示音；后续 TTS 实现只替换输出层。

插件页面 `/link-ets2-nav` 展示数据状态、附近目标及拒绝播报的原因。只读探测工具用于检查本地游戏资源，不需要启动游戏，不随插件 DLL 分发。

## 验证边界

合成地图测试验证路径、方向、距离、去重、时效和生命周期规则；本机资源探测验证文件解析。二者不能替代游戏内测速方向及实际监测位置的标定。
