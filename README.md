# Link ETS2 Nav

面向 Euro Truck Simulator 2 的固定测速探头预警插件，基于 ETS2LA 框架开发。

当前版本提供附近探头识别、方向与路线匹配规则及诊断页面，属于需要标定的开发预览版。**未标定的探头只显示诊断信息，不会自动播报。** 尚未提供完整转向导航。

## 功能与限制

- 接近后读取附近地图区块，识别真实测速挂点，动态计算道路关联，不预生成地图触发点。
- 对已标定目标，优先在沿路约 500 米、200 米处各提示一次；无法取得沿路距离时，仅对已确认在前方导航路线上的目标采用直线距离。
- 无导航时，仅对当前方向的唯一道路及已解析路口连接链上的必经目标提示；存在多个合法出口时不猜测行驶方向。
- 同一次接近的两个阶段分别去重；首次识别已不足 200 米时只提示近距离阶段。暂停、倒车、断线或数据无效期间不提示。
- 支持宿主提示音、本地音频文件和可选的离线 Kokoro TTS；按预计触发顺序提前合成完整语句，并在本地文件缓存中复用。

第一阶段支持官方地图及当前实际挂载的 DLC。覆盖地图、模型或测速挂点的模组会导致扫描暂停并显示原因；普通经济或车流定义不因此被一概禁止。部分预制件内探头、随道路自动调整的标志和未知资源格式尚不支持。方向不明、道路归属不明或未经过标定的目标均不播报。

插件不包含自动驾驶或车道保持功能，不会阻止测速或罚款。

## 安装与使用

本插件由外部程序 ETS2LA 加载，不通过游戏内模组管理器安装。ETS2LA 及其游戏通信 DLL 必须与游戏版本匹配。

将 `LinkEts2Nav.dll` 放入宿主的 `Plugins/` 目录，在插件管理器中启用 **Link ETS2 Nav**。在宿主打开 `/link-ets2-nav` 查看车辆连接、路线状态、附近探头及拒绝播报的原因。开发宿主首页提供相应链接。

预警使用宿主已有的提示音资源，无需单独安装语音服务。没有校准配置时可使用扫描和诊断功能，但不会自动发出预警。校准方法见 [探头标定](docs/calibration.md)。可选语音合成的模型配置与缓存说明见 [开发指南](docs/development.md#离线语音合成)。

工程内对开发宿主的界面和插件加载限制不会随单独的插件 DLL 分发。
